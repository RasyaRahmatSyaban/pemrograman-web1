Rangkuman Materi HTML & CSS

Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa yang digunakan untuk membuat struktur halaman web. HTML menggunakan elemen-elemen yang ditulis menggunakan tag untuk mendefinisikan berbagai bagian dari sebuah halaman web.

  • Tag Utama: <html>, <head>, <body>
  • Tag Heading: <h1> hingga <h6>
  • Tag Paragraf: <p>
  • Tag Gambar: <img>
  • Tag Tautan: <a>

Apa itu CSS?

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mendesain dan mengatur tampilan halaman web. CSS memungkinkan Anda untuk mengubah warna, tata letak, font, dan elemen visual lainnya dari sebuah halaman web.

  • Selector: Memilih elemen HTML yang akan diberi gaya
  • Property: Jenis gaya yang ingin diterapkan (misal: warna, ukuran font)
  • Value: Nilai dari properti yang ditetapkan (misal: red, 16px)
